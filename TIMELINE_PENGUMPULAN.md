# Breakdown timeline LapakBae

| Bagian | Estimasi |
| --- | --- |
| Design system dan komponen bersama | 3–4 jam |
| Halaman publik, login, dan register | 6–8 jam |
| Halaman pembeli dan tampilan alur booking | 4–6 jam |
| Dashboard pemilik toko dan admin | 9–14 jam |
| Penyempurnaan teks antarmuka | 2–3 jam |
| Animasi GSAP | 2–4 jam |
| Pengujian responsif, aksesibilitas, dan perbaikan | 4–6 jam |
| **Total** | **30–45 jam** |

Setara sekitar **5–8 hari dengan 6 jam kerja efektif per hari**. Cakupannya cukup besar karena ada sekitar 30 halaman untuk publik dan tiga role.
